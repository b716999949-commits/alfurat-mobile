استيراد من JSON أو CSV

اختر ملف المنتجات من تطبيقك أو النظام القديم. ستضاف المنتجات الجديدة ويُحدّث الموجود عند تطابق رقم SKU أو معرّف المنتج في التطبيق؛ لا تُحذف المنتجات الحالية.

الأعمدة المدعومةname, category, brand, model, sku, external_id, description, specs, price, old_price, image_url, product_url, video_url, badge, featured, stock

الحقول الأساسية: name الاسم، وcategory القسم. السعر 0 يعني "السعر عند الطلب"، والمخزون -1 يعني غير محدد.

الربط المباشر مع تطبيق المنتجات

تم تحديد تطبيق الفرات موبايل على Google Play. صفحة التطبيق تعرض الوصف العام فقط، ولا تتيح الوصول إلى جميع بيانات المخزون. استخدم ملف تصدير CSV/JSON من لوحة التطبيق أو اطلب من المطوّر رابط API مُصرّحاً له؛ الاستيراد يحدّث العناصر المطابقة بمعرّف التطبيق أو SKU ولا يمسّ الطلبات.
